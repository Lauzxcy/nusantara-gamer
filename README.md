# Nusantara Legends

Website landing page untuk **Pokémon: Nusantara Legends** — fan game turn-based RPG bertema kepulauan tropis Nusantara.

## Live

https://lauzxcy.github.io/nusantara-gamer/

## Isi

| File | Keterangan |
|---|---|
| `index.html` | Struktur halaman |
| `style.css` | Styling & animasi |
| `script.js` | Interaksi: typewriter, counter, Pokédex filter, form |
| `favicon.svg` | Ikon situs |

## Menjalankan lokal

Buka `index.html` langsung di browser, atau jalankan server statis:

```bash
npx serve .
```

## Deploy

Repo ini otomatis ter-deploy ke GitHub Pages dari branch `main` (root). Setiap `git push` akan memicu rebuild.

```bash
git add .
git commit -m "update"
git push
```
